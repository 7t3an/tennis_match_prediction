# 🎾 Tennis Match Predictor - Streamlit App

Веб-додаток для прогнозування результатів тенісних матчів за допомогою Machine Learning.

## 🚀 Швидкий старт

### 1. Встановіть залежності (якщо ще не встановлені)

```bash
pip install streamlit plotly
```

### 2. Запустіть додаток

```bash
streamlit run app.py
```

Додаток автоматично відкриється в браузері за адресою `http://localhost:8501`

## 📋 Функції

### ✅ Що вміє додаток:

1. **Вибір гравців** з випадаючого списку
2. **Автоматичне завантаження** рангу та очок з історичних даних
3. **Налаштування параметрів матчу:**
   - Покриття (Hard, Clay, Grass, Carpet)
   - Рівень турніру (G, M, A, D, F)
   - Формат матчу (Bo3, Bo5)
   - Сіди гравців

4. **Інтерактивні візуалізації:**
   - Gauge діаграма з ймовірністю перемоги
   - Картки гравців з шансами
   - Деталі аналізу (різниця рангів, H2H, очікувана точність)

5. **Інтелектуальний прогноз:**
   - Модель враховує історичні дані
   - Rolling статистику останніх 10 матчів
   - Head-to-Head історію
   - Рівень впевненості моделі

## 🎯 Як користуватися

1. **Оберіть гравця 1** зі списку
2. **Оберіть гравця 2** зі списку  
3. **Налаштуйте параметри** (ранги, сіди, покриття)
4. **Натисніть "ЗРОБИТИ ПРОГНОЗ"**
5. **Отримайте результат** з візуалізацією!

## 📊 Інтерпретація результатів

### Рівень впевненості моделі:

- **>70%** - 🔥 Дуже впевнений прогноз (точність ~73.7%)
- **60-70%** - ✅ Впевнений прогноз (точність ~62.5%)
- **55-60%** - ⚠️ Помірно впевнений (точність ~58.6%)
- **50-55%** - ❓ Невпевнений (точність ~52.2%)

### Що означає ймовірність:

- **80-100%** - Явний фаворит
- **65-80%** - Сильний фаворит
- **55-65%** - Невеликий фаворит
- **45-55%** - Рівний матч (coin flip)

## ⚙️ Технічні деталі

### Модель:
- **Алгоритм:** XGBoost + Probability Calibration
- **Точність:** 68.86%
- **ROC-AUC:** 0.76
- **Features:** 53 ознаки

### Features які використовуються:
1. **Rank-based:** ранги ATP, очки, різниці
2. **Seed-based:** сіди, статус сіяного гравця
3. **Rolling stats:** статистика останніх 10 матчів
4. **H2H:** історія особистих зустрічей
5. **Surface:** покриття корту
6. **Tournament level:** рівень турніру

## 🔧 Налаштування

### Змінити порт:

```bash
streamlit run app.py --server.port 8502
```

### Запустити в headless режимі:

```bash
streamlit run app.py --server.headless true
```

### Відкрити в мережі:

```bash
streamlit run app.py --server.address 0.0.0.0
```

## 📝 Примітки

- Модель використовує історичні дані з 2012-2024 років
- Rolling features обчислюються на основі останніх матчів гравців
- H2H статистика враховує всі попередні зустрічі
- Прогноз може відрізнятися від реальності через форму, травми, та інші фактори

## 🐛 Troubleshooting

### Модель не завантажується:
```bash
# Перевірте що файл існує
ls "saved models/xgboost_calibrated_model.pkl"
```

### Немає даних про гравця:
- Модель використовує середні значення для невідомих гравців
- Для кращої точності додайте гравця в тренувальні дані

### Streamlit не запускається:
```bash
# Переконайтеся що streamlit встановлений
pip install --upgrade streamlit
```
